# Agent 设置页面

日期：2026-10-11。范围：Desktop 单 Agent 创建、编辑与共享运行时配置。已实现。设置为主内容区的二级页面，保留入口的左侧导航。

## 配置职责

| 分类 | 当前 Agent 配置 | 通用 Settings 保留 |
| --- | --- | --- |
| 基础信息 | 内置/本地头像、名称、简介 | 默认 Agent 偏好、Agent 模板安装与列表管理 |
| 角色与规则 | AGENTS.md、IDENTITY.md、SOUL.md、SONG.md | 全局与渠道作用域文件 |
| 模型与能力 | 文本模型、语音识别模型覆盖 | Provider、密钥、模型资源与共享路由 |
| 技能与工具 | 当前 Agent 技能停用、直接工具调用开关 | 技能安装与全局停用、MCP 连接、工具服务配置 |
| 记忆与知识 | 共享个人记忆授权、真实记忆记录检索 | 记忆服务与全局治理 |
| 绑定的机器人 | 当前 Agent 的机器人、新增绑定及移交 | 渠道账号、凭证与连接测试 |
| 高级设置 | 权限、启用、侧栏可见性 | 全局执行权限与隔离、系统与运行时设置 |

## 行为

- 复用现有 Agent ID、工作区、角色文件和细粒度 API。分类切换不提交、不丢草稿；返回/取消放弃草稿并回到入口。Agent 首页设置只替换主内容区域，不打开通用 Settings 覆盖层。通用设置入口保留通用导航。保存成功返回入口页面。
- Agent 技能停用与全局停用共同生效，不能在 Agent 页恢复全局停用的技能。技能匹配与显式调用使用同一个有效目录。
- 工具禁用在共享执行层检查，并移除直接工具列表和延迟工具目录中的禁用项。开关表示工具可用性，执行隔离仍由权限/沙箱负责，不能声称关闭搜索就隔离网络。
- 记忆复用已有 MemoryGateway，按当前 Agent 身份检索 Agent 自身和已授权 owner 记录；显示来源数量和状态。对话/项目记忆仍按具体会话范围召回；新建 Agent 保存后读取。候选审核、后端及维护留在通用记忆中心，不编辑或注入 KNOWLEDGE.md。
- 默认仅展示当前 Agent 负责的机器人。通过“绑定其他机器人”选择原负责人，绑定与移交先进入草稿，固定底栏保存后生效；待保存变更可撤销。非默认 Agent 可移交给 Momo；从 Momo 转交通过目标 Agent 的绑定入口完成，不提供空身份解绑。已有 Session 的身份保持不变，启用状态与凭证不在此处修改。
- 各字段、角色文件和渠道绑定沿各自 API 保存；多次保存请求可能部分成功，失败保持草稿供重试，不声称原子提交。

## Markdown 配置与头像（2026-10-11）

名称、简介和头像是展示元数据，不替代模型身份。Agent 的四个角色文件集中在“角色与规则”：文件选择器显示用途与文件名，下方显示用途说明和单一文本编辑区；切换文件或分类保留各自草稿，统一从固定底栏保存。

| 文件/配置 | 用途与生效范围 | 配置位置 |
| --- | --- | --- |
| 名称、简介 | Agent 列表、首页等展示元数据，不注入角色规则 | 当前 Agent → 基础信息 |
| AGENTS.md | 职责、协作流程和行为边界 | 当前 Agent → 角色与规则；共享规则保留在全局工作区文件 |
| IDENTITY.md | 模型身份、名称与定位 | 当前 Agent → 角色与规则 |
| SOUL.md | 语气、价值观与交流风格 | 当前 Agent → 角色与规则 |
| SONG.md | 可选的补充提示与工作节奏 | 当前 Agent → 角色与规则 |
| BOT.md | Bot/Web Profile 专属协作规则，补充 AGENTS.md | 通用设置 → 对应渠道 Bot 或 Web Profile 编辑 |
| Bot 的 SOUL/IDENTITY/SONG | 当前 Bot 的同名覆盖文件 | 对应 Bot/Web Profile 编辑；只有需要差异时填写 |
| USER.md | 用户背景；属于共享或 Bot 作用域，不是 Agent 记忆数据库 | 全局或对应 Bot 工作区文件；现有 Desktop Bot 表单不提供此文件 |
| TOOLS.md | 本地环境约定，不控制工具可用性 | 全局或对应 Bot 工作区文件；服务连接在通用工具设置 |
| BOOTSTRAP.md | 全局初始化辅助文本 | 全局工作区文件 |
| 项目的 AGENTS.md / AGENT.md / CLAUDE.md | 项目约定，按该顺序发现项目上下文 | 项目目录；不复制到 Agent 设置 |
| Skill 的 SKILL.md | 技能说明与任务流程 | 技能中心/技能目录；Agent 页只选择可用性 |
| 记忆记录 | 结构化记忆检索与授权 | 当前 Agent → 记忆与知识；全局维护在记忆中心 |

当前 Desktop 没有独立的全局 Markdown 编辑页；全局文件仍在工作区维护。推荐未来在通用设置增加“共享规则”编辑入口，复用同一文件选择器，但不改变作用域和运行时合并规则。本次不新建该入口。

运行时对同名文件按 Bot → Agent → 全局选择更具体的内容，空文件允许使用较宽作用域的内容；BOT.md 是独立文件，可补充 AGENTS.md。TOOLS.md 与 BOOTSTRAP.md 是较低优先级的辅助上下文。项目对话有独立规则：无显式 Agent 身份时只加载 USER.md 与项目约定，不应假设所有 Agent 文件参与。设置页面只重新组织已有文件编辑，未修改提示词合并逻辑。

头像提供 12 个随包内置的色块 SVG、恢复默认与本地 PNG/JPEG/WebP 上传（最大 5 MB）。文件选择只生成本地预览；保存时写入 `sessions/<agentId>/avatars/<内容哈希>.<扩展名>`，配置保存服务相对引用，不依赖固定端口或机器路径。相同图片复用文件；替换图片保留旧文件，不做自动清理。服务只读取限定目录中的允许文件名，拒绝目录穿越与符号链接。内置资源进入 Desktop public 与服务 static 构建，不依赖在线头像服务。
