# Pi 扩展安装、管理与运行兼容

日期：2026-11-04。目标是让 Pi 扩展保持原样安装和使用，提供对话安装与设置页管理。用户已确认接受专用终端兼容面板。当前采用官方 Pi 1.4.0 运行时作为兼容基线，不自行翻译任意终端组件。

## 宿主与执行归属

`piExtensionRun` 是当前 Molibot 任务拥有的受管理工具。独立子进程使用官方 `AgentSession`、`AgentSessionRuntime`、`DefaultResourceLoader` 和 `InteractiveMode`，通过公开 Terminal 接口传输 ANSI 与真实用户输入，无需操作系统 PTY。Desktop 使用 xterm 显示终端。标准 select/confirm/input/editor 通过带请求编号的桥接交给所属 Desktop 聊天弹窗，人类回复后返回官方接口约定值；自定义组件、快捷键、动态注册和生命周期保留在官方进程中执行。

原生 Pi 的上下文是绑定父 Molibot Session 的独立 JSONL。主任务记录兼容调用、结果和子调用归属；不能将它称为同一份会话历史。服务器运行方式保留原来的工具和事件桥接；原生方式不再向同一扩展发送主 Agent 的第二套生命周期事件。新配置默认原生，旧配置显式迁移为服务器方式，设置页允许切换。

宿主已配置且启用的内置与自定义聊天模型通过原生模型目录注册，支持在原生会话内选择；默认模型请求经过父任务的原生模型工具，复用权限、审批、预算、用量和未知收费请求保护。Provider 事件回调留在内存中，经相关请求关联；不得把函数写入持久化参数。恢复后缺少原回调时拒绝重新发送。扩展自定义 Provider 在子进程运行，但模型工作先获得宿主准入并回报用量；默认宿主模型凭据不传入子进程。默认文件、shell 等工具代理父任务能力；终端 `!` shell 也通过受控工具入口。

扩展代码是所有者信任的本地代码。它直接调用 OS、网络或自己的依赖时，进程隔离不提供权限沙箱，也不保证这些私有请求都能被宿主计费。不能通过提示词声称已建立这样的边界。

明确的 `@pi/扩展ID` 选择和开头使用已启用扩展的执行指令在共享 Runner 绑定原生入口，不经过主模型的工具选择；不可用的显式 ID 拒绝替代执行。普通提及、引用、否定与诊断性问句不触发此路由。观察图片与最终附件分别管理，只有显式选定的图片进入渠道。

## 安装与设置

`extensionManage` 与设置页共享安装服务，接受 npm、Git 和子目录来源。工厂校验使用有期限、内存上限的子进程；npm 包保留提升到同级的运行依赖；借用父目录依赖的 Git 子目录（包括 npm workspace）保留完整依赖布局，并将资源清单限定到所选子目录。正式发现与原生执行使用官方包资源解析，支持多入口、glob 排除、skills、prompts 和 themes。已保存的 flags 只传入声明该 flag 的已启用扩展。

Desktop 模块提供来源检查、安装、搜索、总开关、单项启停、运行方式、重载、错误详情和确认卸载。单独名称有歧义时先确定具体来源；目录存在不等于加载或执行成功。保存失败回到已提交状态，旧服务响应不能覆盖新服务列表。Web 使用相同安装、启停与运行方式 API，并显示原生交互需要 Desktop 的提示。

安装服务的更新记录、版本回滚、并发安装和所有 Pi 包来源形式仍需分别验收，不能仅凭兼容运行时已接入就标为完成。

## 输入、停止与恢复

- 终端只能控制父任务已启动的兼容执行，HTTP 控制接口不能独立启动收费 Agent。
- 同一父 Session 同时最多一个原生执行；终端输入、输出、尺寸和保留数量有界。兼容调用最长一小时；终端交互无客户端时立即失败，客户端租约为 5 秒，单次交互最多 5 分钟。等待输入时仍可由父任务或用户停止。弹窗草稿按请求保存；后台待答在所属 Agent 行提示，不跨页面弹出。
- 终端入口仅在当前聊天有自定义交互或未核对中断时显示；首页、设置和其他页面隐藏。标准交互在所属聊天弹窗，自定义终端由用户主动打开，不抢占聊天焦点。隐藏不停止，停止撤销模型、工具和待答交互；不响应取消的子进程在宽限后终止，并标记清理未知。普通扩展的清理回调结束不代表操作系统共享释放已获独立验证；LCU macOS 增强额外执行本轮 controlStatus → controlStop → controlStatus 核验，再 turnEnded 和 close。未完成时保留清理连接，重试不借用下一轮身份，不触发模型或重放工具。
- 宿主工具或模型出现长审批挂起时，保留原审批结果并挂起父任务，停止原生 JavaScript；不进入第二轮模型工作。
- 未完成的原生状态在重启后仍阻止自动重试。用户核对副作用后允许新上下文，原 JSONL 和状态记录保留至会话永久清除。普通失败仍需核对，不能根据错误类型推断没有副作用。
- 永久清除独立清理原生上下文与内存输出，不依赖 Agent Context 枚举；有活动写入者时拒绝清除并保留重试意图。备份范围与环境继承见功能说明。
- 原生进程的内存续体不能跨崩溃或审批挂起恢复，不承诺自动续接任意扩展脚本。

## 验收证据与剩余范围

| 范围 | 已验证证据 | 剩余范围 |
| --- | --- | --- |
| 默认模型归属 | 真实 Runner 调用原生 Pi，预算和用量归属父 Session；本地 OpenAI 模拟服务验证自定义模型切换；回调不进入持久化参数 | 真实付费 Provider 和各类 Provider 事件逐项验收 |
| 命令、flags、动态工具 | 终端 `!` 经受控 shell 的回归通过；真实 Runner 原生命令无需主模型请求；原生注册与工具执行本地夹具通过 | 不同第三方包组合和命名冲突 |
| 自定义 UI | 官方组件工厂留在子进程，真实 Enter 返回用户选择；Desktop ANSI 与按键回归 | 各平台快捷键、复杂编辑器、媒体终端协议；内置 `/new`、`/resume`、`/fork`、`/model` TUI 路径 |
| 包资源 | npm 依赖保留、Provider-only 安装、glob 排除、skills 和 prompts 夹具通过 | themes 展示、原生依赖、旧命名空间和更多来源语法 |
| 中断与恢复 | 等待输入时停止、同会话并发拒绝、审批挂起无第二轮、重建宿主后人工核对 | 原生安装包、Windows 进程组清理及真实崩溃环境走查 |
| 设置 | 临时数据库整对象 round-trip、旧配置 mode 迁移；管理页安装和重启回读 | 自动更新与版本回滚 |

全部扩展兼容必须限定 Pi 版本、平台及扩展依赖。LCU、外部服务、原生模块或私有 Pi 内部接口需要各自验收。当前状态为部分交付；没有安装实际第三方扩展或使用真实账号，不能宣布整个生态已经通过。

Telegram、飞书等渠道需要 Desktop 接管终端交互；当前没有将任意 TUI 翻译为渠道原生卡片。标准输入的跨渠道转发、Web 专用终端入口也未交付。
