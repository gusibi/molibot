# Pi 图片生成接入验证

日期：2026-10-03。范围：四项能力 spec 阶段 4B。状态：代码接入与本地验收完成，真实 Provider 待验证。

## 可用入口

现有图片设置增加 Pi 引擎，模型目录只返回 Pi 的 image 类型；凭据来自共享 Models/CredentialStore。现有 imageGenerate 工具、图片任务和文件发送入口保留，多个输出分别落盘并记录顺序、MIME、字节数及伴随文本。Web/Desktop 使用输出索引预览与下载。

Pi 原生操作尚不接受 size/seed，传入时明确拒绝；参考图只允许支持 image 输入的模型。不会自动重试付费生成。未知 usage 保留为空，SDK 错误、取消和空图片不会变成成功。

## 机器证据

- 图片 adapter、工具、费用归属与 Desktop 汇总、自动引擎选择回归 40 项通过：缺少凭据、参数/能力拒绝、参考图、错误与取消、多输出加文本、usage 缺失。补充私网地址与超大参考图拒绝、Pi HTTP 日志不读取图片内容、首图实际后缀与部分落盘失败保留制品回归。真实工具生成后关闭并重开临时数据库，经实际下载路由逐张核对 MIME 与字节；通过真实飞书图片适配器及模拟传输验证逐张上传和图片消息。费用在 SDK 返回后立即保存，覆盖取消、首张 MIME 拒绝和后续落盘失败；删除处理中任务后，迟到写入仅保留费用与真实终态，不恢复内容。
- 图片设置 sanitizer 与 Desktop 媒体契约 27 项通过；设置 save → 新 store → load 使用临时数据库验证整对象，包括既有与自定义引擎。
- 图片与 Durable 联合回归 48 项通过；Pi 工具 usage 与结果一起提交，恢复复用不会再次调用生成工具。
- TypeScript 检查与生产构建通过；Desktop Svelte 检查 0 错误、1 条既有警告。

## 实际页面证据

临时 DATA_DIR、本地端口、外部渠道禁用、付费凭据清空。Web 首次打开图片设置后选择 Pi 模型并保存，中英即时切换与识别/生成 Tab 切换正常。刷新保留配置；终止隔离服务并同目录重启后，新页面恢复相同引擎开关和模型。390px 宽度无横向溢出，使用已有主题与保存底栏。多图夹具在真实详情页显示伴随文本；选择第二张后，预览 src 与下载链接同时切换为 index=1。

隔离 Desktop 前端真实组件首次打开图片设置、详情和用量页，显示两张图片、伴随文本及 $0.030000 估价；Web 时间筛选显示同一笔费用；Desktop 用量页在 390px 宽度下无横向溢出。该浏览器预览不等同于原生 Tauri 冷启动。

独立标识的原生 Tauri 验收构建使用临时 DATA_DIR、独立端口、禁用外部渠道和清空付费凭据。首次打开图片设置成功，避免遗漏模型目录的原生 HTTP 权限；真实 WebView 展示多图与伴随文本，选择第二张后下载 blob 更新。中断该实例的服务后，桌面监督器以新 PID 恢复相同端口；切换用量页再回图片设置，Pi 开关、费用和持久化图片仍可访问。未中断用户主实例。

## 审查结论

两项费用丢失属于持久化顺序与异步竞态问题，已在共享图片 adapter/store 修复；临时数据库回归覆盖整类提交窗口。未发现需要新增长期协作规则的重复根因。实现与规范双轴复核未发现新的必修问题。

## 费用与预算

统一用量从同一图片任务库读取费用事实，不建立第二份计费账本。全局、会话、Bot、渠道及 Web/Desktop 筛选汇总包含已知图片估价和未知价格请求数；重复读取、重启与删除不复制或丢失费用。Agent 图片调用沿用共享工具调用预算，当前没有新增美元支出硬上限。SDK 估价不是 Provider 实际结算金额。
