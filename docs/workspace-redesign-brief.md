# 桌面功能工作区重设计

2026-10-15 确认。四个功能保持独立页面，采用紧凑、稳定的桌面工作区。长期设计约束以 [DESIGN.md](../DESIGN.md) 的“功能工作区”一节为准。

## 页面与布局

| 页面 | 结构 | 主要调整 |
|---|---|---|
| 自动任务 | 固定列表与详情 | 启用/暂停分组、短标题、调度与执行结果分开、详情未选中占位 |
| 技能 | 紧凑卡片网格 | 搜索点击展开，范围与数量在下方，卡片底部整合启停和详情 |
| 计划 | 固定列表与详情 | 去外框与嵌套卡片，状态分段筛选，详情操作置顶，返工支持取消和完整性检查 |
| 小程序 | 图标启动台 | 搜索在标题栏，数量行左侧显示统计、右侧显示管理，生命周期操作留在管理页 |

四个页面仅通过左侧导航切换，不在内容区重复做跨功能 tabs。

## 共享交互

- 42px 窗口标题栏保留原生窗口按钮簇的位置。页面通过现有 ChatHeader 发布标题与操作。
- 分类、筛选和数量位于内容区顶部，不进入窗口标题栏。
- 四页搜索统一为标题栏图标，点击原位展开并自动聚焦；关闭或 Esc 清空搜索、收起输入框并还焦点。
- 四页在内容区顶部显示页面说明；自动任务和计划沿用现有中英文说明。
- 创建和刷新保留在标题栏，每个功能仅显示一个图标并提供悬浮提示；只有刷新时直接显示刷新图标，不放入更多菜单。小程序数量靠左，管理图标放在同一行右侧，管理页返回入口保留在标题栏。
- 自动任务分类、技能范围和计划状态使用下方直接可点的共享分段按钮；自动任务与计划筛选项显示数量、窄窗横向滚动，两页说明与分隔线保持同高；卡片使用中性边框和状态文字，不使用绿色侧线。统计位于下方，错误反馈保持可见。
- 主从页左列固定 320px，不随宽窗放大；窄工作区切换为列表/详情单列，不增加覆盖浮层。
- 未选中对象时，右侧复用启动页 Agent City 插画与简短引导。
- 返回列表保留搜索与滚动位置；计划后台刷新不重新打开已关闭的详情。

## 主题

结构、操作位置与信息层级一致；字体、圆角、边框、阴影、透明度和颜色沿用现有主题 token。Product、Bold 和导入主题各自保持既有表达方式，不硬编码 macOS 的材质。允许中英文和主题字体产生正常换行。

选中背景与文字使用 selection/on-selection 配对；状态配文字或图标，不仅依赖颜色。中文标题不使用负字距，时间和计数使用表格数字。

## 验收

真实 API 操作及保存结果、无匹配搜索、四页导航、任务选中前后列宽、计划进度、技能启停、小程序管理往返、860×620、中英即时切换、代表主题及导入主题、隔离服务重启。

视觉草稿中的任务名与时间属于示例。当前任务接口未提供下次触发时间，页面只展示真实执行计划。本次不修改调度器、持久化字段或原生窗口实现。

计划返工在正文顶部展开，取消清空草稿；任一任务缺少名称或有效步骤时，不允许继续添加或保存。

技能管理入口统一在外侧技能工作区，复用现有卡片与详情展示内置技能安装、更新、覆盖修改及版本信息；不新增管理面板。设置中的 Skills 只保留技能搜索配置与固定保存栏。默认侧栏顺序为自动任务、计划、技能、小程序。

- 小程序管理与返回在内容区同一位置切换；AI 设置使用管理工具栏图标及中英悬浮说明，移除通栏入口。

- 技能与小程序共用内容列宽，说明、工具栏横线与下方网格左右对齐；嵌套工具栏填满父列，不重复扣页面边距。

- 小程序说明与所有下方内容共用一个限宽容器，1240px 上限；宽窗口中保持居中内容列，不使用整页宽度。
