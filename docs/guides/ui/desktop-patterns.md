# 桌面布局、组件与动效实现指南

修改桌面窗口框架、侧栏、设置与数据页、Inspector、聊天时间线交互或动效实现时读取。通用设计原则见 [DESIGN.md](../../../DESIGN.md)。

## 1. 窗口顶栏与侧栏导航 (Window Header & Sidebar)

- **唯一全局顶栏 (`ChatHeader`)**：
  - 整窗仅有顶部第一行（42px）作为全局顶栏，横跨侧栏与主内容列（1–2 列）：左侧固定预留原生红绿灯（84px），其后紧接**标题栏控制簇**（槽位 1 固定为侧栏折叠切换；槽位 2 在侧栏展开时为全局会话搜索，折叠时为新建对话且点击同时展开侧栏；控制簇绝不随侧栏动画位移），右侧由当前页面发布标题、来源与操作按钮。各页面不得在内容区再渲染第二条标题栏。
  - 展开态顶栏通过 CSS `subgrid` 继承侧栏与聊天列轨道，标题起始于聊天列左缘，边界以文本高度（`--fs-label`）、1px `--content-frame-edge`（65% 不透明度）竖向细线分隔；折叠态回退为单行 flex 并隐藏该细线。
  - **来源标签展示**：本地 Web 会话省略来源；外部渠道会话在标题后以次级文本显示完整本地化渠道名（不加徽标、首字母或斜杠）；项目会话先显示会话标题，后跟项目名称作为次级标签。
  - **拖拽与浮动内容框**：整个 42px 顶栏属于原生拖拽区（按钮接收点击，空白与被动标题透传给拖拽遮罩）。顶栏与侧栏共享底层原生材质平面；下方聊天区与打开的 Inspector 共处一个带 `--content-shadow` 的内嵌浮动框中（右侧与底部留 8px 边距，阴影绘在统一外框叠层上，两列仅由 Inspector 左边框分隔）。
- **侧栏、折叠栏与会话树**：
  - Chat 与 Settings 共用 `228px` 基准可拖拽侧栏（最小钳制 228px，低于 160px 阈值自动吸附折叠，宽度仅在指针释放时持久化）与底部标识组件 `AppFooterMark`（仅显示带状态圆环的 Logo 与应用名，不写“已就绪/Online”文字；Chat 底栏配 Filled `Settings2` 整行打开设置，Settings 底栏配 duotone `Users2` 返回默认 Agent 首页）。
  - **折叠图标栏与浮层**：折叠后第一列保留 `48px` 图标栏（不放新建对话按钮）；点击 Agent、项目或 Agent Team 在图标栏右侧展开按需浮层，直接复用同一个 `SidebarLists` 组件（记住展开宽度，选中会话时保持打开，按 `Escape`、切到其他目的地或再次点击同一图标时关闭）；点击自动任务、技能、计划、小程序则直接打开对应工作区面板并关闭浮层。
  - **会话树对齐与吸顶**：一级分区头（Agent / Agent Team / 项目）、主导航行（30px 高，从 42px 顶栏下方开始）、渠道头与项目文件夹共享左对齐基准与 16px 图标列；二级内容统一通过 `.sidebar-tree-children` 缩进 12px。会话行不显示 Bot 头像，预留槽位仅显示静态状态点、分叉标记或运行中的 16px 3D 点球动画 `RunningOrb`。项目文件夹展开时切换为 `folder-open` duotone 图标。一级分区头在同一滚动容器内共享顶部吸顶槽位（带渐隐模糊遮罩，不叠第二标题）。

## 2. 设置、数据页与多列工作区 (Settings, Data Pages & Workspaces)

- **设置页与跨入口编辑器**：
  - 设置页使用稳定左栏、`PageHeader`、居中 `SettingGroup`（720px 列宽）与固定 `.settings-footbar`。窗口宽度 `≤ 600px` 时左栏收窄至 `128px`，设置行控件纵向堆叠。
  - 当同一配置概念同时出现在全局设置与实体弹窗（如项目自动任务）时，两者复用同一套列表、编辑器、调度器与历史组件；实体入口锁定目标且独立于常规设置表单保存，弹窗外壳保持固定视口尺寸，切换内部标签页不改变弹窗大小。
  - **AI 服务商 (Providers)**：在 Web 与 Desktop 共用主从布局（左侧服务商列表负责搜索、筛选、状态与新建；右侧详情负责鉴权、默认值与模型清单，远程发现与单模型编辑使用独立弹窗，窄窗下列表折叠到详情上方）。
- **数据页（用量 Usage、Trace、服务日志）**：
  - 共用 720px 阅读列、紧凑指标条与主图表。筛选栏保持紧凑单行（常用维度直接可见，精确 ID 与诊断字段收入可展开折叠区，时间范围分段按钮与刷新同处浅顶栏，筛选项间距 12px，筛选区与首张汇总卡间距 24px）。
  - Usage 与 Trace 默认展示“今天”（今天/昨天按配置时区展示小时桶，更长窗口展示零填充日桶）；MCP 调用独立于普通工具调用统计；Agent 性能摘要展示运行完成率（代表执行状态而非语义质量）、已知模型美元成本与缓存命中率（未知价格保持显式未知）。图表搭配语义色、数字与纹理（缓存读取与未完成请求使用纹理区分），零分母显示无数据。
- **主工作区与右侧 Inspector**：
  - 主工作区（自动任务、技能、计划、小程序、Agent）共用居中容器 `--workspace-col: min(1200px, calc(100% - 48px))` 与 `stable both-edges` 滚动槽位。
  - **右侧 Inspector 槽位**：聊天同时最多打开一个右侧 Inspector（文件 Inspector 与小程序 Inspector 共用同一网格轨道、宽度存储與拖拽手柄，打开其一自动关闭另一个，绝不产生第四列）。Inspector 自身顶栏（含 Files / Mini Apps 切换、搜索与关闭）位于全局 42px 顶栏行的第三列，背景透明。打开期间缩放窗口时，宽度增量由 Inspector 吸收，侧栏与聊天列保持原宽。
  - **File / Artifact Inspector**：采用 Primer 风格代码库层级（源码树 + 不透明预览/编辑区，使用共享语义 token 与文件语言着色，选中行不把文件图标压灰；变更列表显示 `+added / -deleted` 行数，diff 行号槽随代码同步滚动）。聊天与 Inspector 的代码块共享同一套亮/暗语法高亮 token。
  - **文档与富媒体预览**：
    - **Mermaid 与 D2**：共用紧凑的 Preview / Source 分段切换、源码复制与全屏缩放检视；D2 通过桌面服务端接口渲染为 SVG Data URL，服务不可用时回退展示源码。
    - **CSV / Excel / DOCX / PPTX**：Markdown 表格产物走 UTF-8 CSV 预览（防中文乱码）；`.xls`/`.xlsx` 使用粘性表头与等宽单元格（单表懒加载上限 5,000 行）；`.docx` 经 Mammoth 懒加载渲染并禁用外部资源；`.pptx` 在画布上按页居中纵向滚动渲染并禁用外部超链接与远程字体。格式损坏或超限时均展示可恢复错误态并保留下载/外部打开按钮。
  - **小程序 (Mini Apps) 与便签 (Note)**：主导航默认打开 Launchpad（64px 圆角矩形图标 + 名称网格，仅展示已启用且健康的应用，管理入口切换至同一管理组件视图）；聊天顶栏提供小程序快捷弹出菜单（含搜索、收藏与最近 10 个打开记录）。Note 卡片阅读态渲染安全 Markdown（禁用裸 HTML、远程图片与不安全协议），通过宿主版本号（revision）按需同步。

## 3. 聊天时间线、输入区与执行过程披露 (Chat & Process Disclosure)

- **助手身份与消息底栏**：
  - 助手身份作为单行锚定在阅读列左缘（头像 + Bot/Web Profile/应用名 + 绑定的 Agent 名），头像不占左侧缩进列，正文与输入区同宽。
  - 已完成回复在列宽充足时内联展示时间戳（今天仅时间、昨天带本地化“昨天”、更早带日期、跨年带年份）、模型/服务商、耗时、工具/文件/token 统计、记忆来源与常用操作；当**消息列宽度**（非视口宽度）低于紧凑断点时，次级元信息与小程序扩展动作合并入右对齐的更多菜单（指针移出触发器与菜单后自动关闭，保留键盘与 `Escape` 支持）。外部只读会话仅在底部显示一行来源与只读说明，不在顶部重复横幅。
- **输入区 (Composer) 细节**：
  - **Bot、权限与模型控件**：Bot 选择器触发器仅显示首字母（从审定色阶中取确定性低饱和底色，相邻项区分颜色）；权限触发器仅显示模式图标与名称（无下拉箭头）；模型与思考深度合并为一个自定义键盘可达弹出菜单（支持原位概览→列表切换与内部滚动）。
  - **上下文用量环 (Context-usage Gauge)**：紧邻模型摘要常驻显示进度圆环（满圈为 100% 窗口容量），点击打开只读毛玻璃面板（展示 `已用/窗口（百分比）`、进度条、各类别占比及平均缓存命中率；无快照旧会话降级展示消息报告用量，0% 缓存命中率如实保留）。
  - **行内实体胶囊与 Skill 引用**：输入中的 `/command`、`/skill`、`@miniapp`、`@[file.md](path)` 与持久化的 `[$Skill](.../SKILL.md)` 在输入叠层与消息时间线中保持统一类型配色（命令强调色、Skill 紫色、小程序青色、文件灰）；持久化的 `[$name](.../SKILL.md)` 渲染为标准 Skill 调用卡，绝不把本地 `SKILL.md` 路径暴露为普通链接（`pitfall #39`）。
- **页内搜索与提问导航器 (Search & Prompt Navigator)**：
  - 会话内搜索位于顶栏操作行文档流内（打开时可原位替换搜索图标，不绝对定位遮挡标题），在普通聊天与项目聊天间共享匹配计数、上下跳转与焦点恢复。
  - 当稳定用户提问达到 5 轮及以上时，时间线视口右侧显示共享提问导航器（仅为用户回合生成 2px 高、间距 10px 的紧凑刻度；悬停或聚焦展开不透明高对比度预览：1 行用户提问 + 最多 2 行助手回答；点击跳转前先将滚动控制权交还用户，发送新消息时恢复底部跟随）。
- **统一过程披露（「查看过程」）与结果分离**：
  - 每轮回答只有一个**统一过程区**（等待模型时入口显示「正在思考」，工具运行时显示对应动作，开始输出结果及结束后显示「查看过程」；无过程内容的纯文本回答不显示空入口）和一个**独立结果区**（仅承载运行时明确提交的完整或中断前部分交付，复制、搜索与预览仅消费结果文本）。
  - 实时与历史阶段过程区均**默认收起**，结构化状态与耗时合并在同一个可展开入口，不另设状态行；用户手动展开后不被后续流式增量重置。待审批请求、待决定计划和需人工处理的失败直接展示在过程区之外。
  - **时间线顺序与分组压缩**：展开后按真实到达顺序呈现思考、进度说明、工具调用与结果（思考使用与工具同轴的普通文本节点，不再嵌套折叠标题）。运行中、失败、未知类型或耗时超过 1 分钟的已完成工具调用保持独立行（运行中命令默认展开最近 12 行真实尾部输出与实时耗时，不从耗时推断百分比）；相邻的成功读取、修改、搜索或短命令可压缩为单条可展开动作行，但不跨思考或叙述边界合并。折叠摘要仅报告耗时、工具调用数与变更文件数，不报思考分片数。
  - **回合产出文件列表**：已完成回答下方可展示与 Artifact Inspector 共享的平面产出文件列表（标明 Created / Updated 状态与文件名，不拆分为两个分区，点击打开当前最终内容）。
- **会话系统状态条**：
  - 每个用户回合的最终运行状态显示为居中的系统状态条（细分隔线 + 状态图标 + 明确文字：已完成、失败、已停止、等待审批），以运行回执的最终结果为准（不用回执中的 `finalText` 伪造缺失正文；重试后成功标为已完成并保留恢复诊断；外部回合仅有输入尚无结果时显示“尚未收到运行结果”）。错误详情以纯文本换行展示在状态条下方，不生成空白助手气泡；状态条仅作展示，不回灌模型。

## 4. 动效、滚动跟随与流式交接实现 (Motion & Scroll Handoff)

- **三级交互时长与表面过渡契约**：
  - **Micro (`100–160ms`)**：悬停/按压反馈（主按钮 `100ms` 按压微缩，开关触觉压缩）、复制变勾、箭头旋转。
  - **State (`160–240ms`)**：消息入场、弹出菜单/Popover/命令面板/轻提示（统一用 `--duration-fast: 160ms` + `--ease-spring`）、折叠内容展开（仅动画展开内容，严禁动画 `height`）、工作区异步加载/错误/就绪局部切换（`160ms` 透明度过渡）。
  - **Panel (`240–300ms`)**：设置页与主工作区内容切换（外壳稳定，内容 `240ms` 透明度 + `6px` 纵向位移）、通用弹窗（`240ms` 弹簧面板 + `160ms` 遮罩）、右侧 Inspector 开合（`300ms` 透明度 + `12px` 横向位移，关闭时先反向退出再释放状态）。
  - 可变数据列表支持基于 token 的入场/退场与 FLIP 重排，但实时文本筛选必须立即生效。Agent Studio / Agent City 的 Three.js / SVG 场景动画独立于桌面 UI 动效系统。
- **时间线弹簧跟随 (`stickToBottom.ts`)**：
  - 时间线底部跟随是唯一由 JS 驱动的动效：在 `scrollTop` 上运行可打断的 rAF 半隐式物理弹簧（与帧率无关，随流式内容增长逐帧重设目标，禁用无法重设目标且与触控板冲突的 CSS `scroll-behavior: smooth`）。
  - 用户首次向上滚轮或触摸立即取消弹簧并交还滚动控制权；滚回底部附近重新激活跟随；切换会话直接落到底部，不播滚动动画。
- **流式转持久化无感交接 (`settleEntrances.ts`)**：
  - 消息入场动画通过 CSS `@starting-style` 配合 `.settled` 类门控，切换会话时不重播历史消息入场。
  - 当流式回复结束并被持久化消息行替换时，回合结束刷新在同一渲染批次（flush）移除流式节点并重绑持久化行 key，利用 `sending` 下降沿抑制该帧入场淡入，使交接在视觉上完全静止（发送时的乐观用户气泡与首个流式行仍保留入场淡入）。
- **运行态光环 (`BeamRing`) 与无障碍定格**：
  - 回合运行期间，前置状态胶囊、底部「回到底部」胶囊与输入区停止按钮外缘佩戴 `BeamRing`（掩码在宿主外缘 2px 的主题强调色锥形渐变环，每 `2.8s` 旋转一周，无需 `overflow: hidden` 裁切）。
  - 在 `prefers-reduced-motion: reduce` 与 `data-performance="low"` 下，所有面板/弹簧过渡降级为瞬时切换；侧栏 `RunningOrb`、思维波浪与 `BeamRing` 停止旋转并定格在静态代表帧，保留状态可见性。
