# 桌面页面与工作区交互规格

修改 Agent 桌面首页与交接、Agent 设置、迁移弹窗、设置分类导航、四大功能工作区（自动任务、技能、计划、小程序）或应用图标身份时读取。通用视觉、无障碍与共享组件规则见 [DESIGN.md](../../../DESIGN.md)；页面条目不授权新增未排期功能。

## 1. Personal Agent 桌面、侧栏与交接首页

- **侧栏导航顺序与 Agent 分组**：
  - 侧栏展开与折叠保持同一顺序：**新对话、自动任务、技能、计划、小程序、Agent、Agent Team、项目**（新对话固定第一位，不设旧“对话”分组或独立 Agent 工作区按钮）。
  - `Agent` 分组首项为“**总览 / Overview**”（打开动画状态总览页），其下直接列出各 Agent 身份入口（默认 Agent 置顶，其余按全渠道最新对话时间倒序、同名按拼音/首字母排序，无对话排后；编辑配置不改变排序时间）。
  - 点击 Agent 名称进入该 Agent 首页，名称旁独立 `＋` 进入该 Agent 新对话草稿（不展开侧栏会话列表，也不请求侧栏分页）；已删除 Agent 与未归属历史入口（仅存在未归属对话时显示，含归档、不含回收站）打开右侧完整历史。
  - **状态呈现**：Agent 行与首页 96px 圆形头像（方图放大裁切填满圆形，未设或失败回退至与侧栏一致的 Molibot Logo）右下角角标仅用形状 + 颜色表达真实非项目运行状态（Project 会话运行态仅在项目内统计）：执行中用 `Run` 奔跑图标（侧栏行带轻微呼吸，降级模式下静态）、空闲用 `MoonSleep` 睡眠图标（严禁用暂停图标）、完成用 `Check`、失败用 `X`、停用用 `Minus`。点击首页头像或状态直接进入总览并定位该 Agent。
- **Agent 欢迎首页、会话顶栏与完整历史**：
  - 普通 Agent 新对话首页居中展示 96px 头像、名称、次级简介、居中输入区、三个快捷提示卡片与最近对话（最多四条的单列紧凑行；复用 `AgentConversationRow`，展示渠道图标、标题、预览、来源与更新时间）。
  - **默认 Agent 工作首页（Home Handover）**：按 [Personal Agent 工作首页 UI Spec](../../designs/agent-home/personal-agent-dashboard-ui-spec.md) 展示：容器最大 `1152px`；顶部为身份、真实读取时间与交接摘要；主区可用宽度 `≥ 960px` 时采用约 `2:1` 双栏（左成果、右待决定，仅待决定时占满全宽；低于 `960px` 按待决定 → 成果 → 执行记录单列排列；低于 `600px` 侧栏收为覆盖导航且背景 `inert`）。成果主卡完整展示预览，其余默认 3 条可展开；待决定默认 3 项（复用审批、Decision Request 与 Plan，权限命令折叠，断连禁用变更）；执行表默认 5 条，失败详情置于全宽执行区下方，不以大面积警告底色占据成果区。`1440×1024` 标准场景首屏须保留完整新任务输入区。交接页不创建 Session，首次发送才建 Session。
  - **首页信号与最近对话**：跨平台回复摘要与下一次真实安排合并为单行紧凑信号带（图标 + 一句事实 + 来源/时间，不铺满整行）；没有成果和待决定的交接首页与工作首页同宽（1152px），结论使用页面级字号并向次级文本收敛。最近对话使用单列紧凑行账本（最多四条），每行占一整行并以发丝分隔线分栏而非卡片墙，显示渠道图标、标题、预览、来源与时间，保留共享会话行的打开及右键操作；完整历史维持列表。普通首页的快捷提示使用卡片，点击只填入草稿。窄窗信号与行内容自动截断，输入区保持真实发送入口。
  - **会话顶栏与更多菜单**：已有会话顶栏标题旁显示可点击的 Agent 名称文字按钮（点击或键盘激活返回对应 Agent 首页，不参与窗口拖拽；未归属/已删除仅显示普通文字），右侧依次排列**历史对话**（duotone `History2`，打开该 Agent 全部历史）、**小程序**、**更多操作**（Reicon `More` Outline，内含展开当前对话搜索、复制会话目录、在 Finder 打开目录、分隔线下方的可恢复删除）与最右侧的**文件产物**。可输入 Web 会话不显示刷新按钮；外部只读会话的刷新图标置于底部只读提示旁。
  - **完整历史与批量管理**：在主内容区展示，顶部提供返回首页、搜索与来源筛选下拉（控件高 40px），支持单条右键删除、多选、选择当前已加载条目与批量移入会话回收站（逐项反馈失败并保留未成功项）。
- **Agent 文件与附件页**：
  - 从 Agent 首页顶栏文件图标（Filled `Library`）或左侧有效 Agent 右键菜单（依次为：全部对话、文件与附件、设置）进入。
  - 按“生成内容、上传附件、来源待确认”三区及媒体/代码/文档类型分组，组内按时间倒序展示自适应卡片网格（图片显示缩略图，其余显示类型图标、文件名、渠道、来源对话与完整时间；注明数量仅来自已加载分页）。点击预览复用 `ArtifactPanel`，窄窗切换为单列预览并提供返回列表入口。

## 2. 设置导航、Agent 设置与存储迁移

- **通用设置外观**：界面与启动 → 外观（明暗、主题家族、导入主题、Logo）→ 软件更新。主题缩略图展示简化界面结构，选中主题与 Logo 使用勾选标记配合主题色；自适应网格容纳中英文标签。
- **设置页七组唯一分类轴**：
  - 设置左栏按“这一页配置什么”分为七组（由导航守卫测试强制一一对应）：
    1. **通用**：应用外观（主题选择、主题导入、Logo 相邻排列）与行为。
    2. **模型**：模型、AI 服务商、决策模型。
    3. **助手**：Agent、渠道（Web 与外部渠道同页管理，不设独立 Web Profile 页；渠道 Bot 与 Web 实例共用编辑器，初始绑定 `default` Momo，不提供空身份兜底）、技能检索（仅配置技能搜索服务商/模型/参数）、记忆。
    4. **能力**：搜索、图像、视频、语音、MCP、连接器、插件。
    5. **数据与历史**：会话管理、运行历史、用量、Trace、服务日志。
    6. **安全与权限**：执行与权限、审批管理。
    7. **系统**：系统、运行环境、诊断。
  - 运行通道类设置页（向量模型、决策模型）顶部先展示当前启用对象与策略摘要条，下方用平面行展示通道列表（Active 项用强调色轨道与浅底标记），编辑连接进入共享对话框。向量模型未配置时摘要收起为一行横向空状态（向量图、说明与主操作同排），本地服务命令单独成组；决策模型在候选模型不可用时摘要与对应行显示「待配置」，标题、说明与策略预览同步描述回退行为，不只把按钮置灰。
- **会话管理**：首屏保留状态计数、搜索、来源筛选与会话列表；高级筛选按需展开。批量操作在选中后显示，操作影响可展开查看，回收站删除明确标为“彻底删除”。更改单项选择会退出跨页全选。自动归档策略展开时才读取，固定保存栏只负责该策略。
- **用量活跃统计**：年度图固定为配置时区内截至今天的最近 365 天，可切换请求次数与 token；模型、Agent、Bot、渠道筛选同时作用于年度与短期统计，短期日期按钮不改变年度窗口。累计、单日峰值与最长连续天数依据全部留存记录；今天尚无请求时，当前连续天数从昨天起算。日格支持点击、方向键与明细文字；窄窗在图内横向滚动。场景频率按请求次数排序，入口分类依次采用小程序、图像、转写、项目、会话归属，其余显示未归属；不分析对话主题，不将模型请求视为提问次数。
- **运行历史**：只读查看最近最多 200 条记录；顶部说明计数范围，结果计数可筛选，搜索、Bot 筛选与分页只作用于已加载记录。列表先展示结果、时间、耗时与摘要，运行 ID、工具和后续建议按需展开。首屏加载保留工具栏；后台刷新保留列表，错误在页内重试。
- **Agent 与渠道目录**：共用关键词搜索、全部/已启用/已禁用计数与匹配数。Agent 优先展示头像、名称、默认标记与简介；渠道增加平台筛选，优先展示实例名称及关联 Agent 名称。ID、权限与其他配置明细按需展开。“已启用”只表示配置状态，不表示渠道在线。编辑保留直接入口；删除收进更多菜单，确认框标明对象名称，取消后焦点返回触发按钮。首次加载失败原位重试，刷新失败保留列表；切换服务后旧响应不能覆盖新结果。模板列表默认折叠并提示可用更新。
- **共享配置与单 Agent 二级设置页**：
  - Agent 列表上方的“共享配置 / 全局 Agent 的设置”并列提供全局 `AGENTS.md` 编辑（所有 Agent 读取，仅保存该文件）与默认新对话 Agent 选择，说明按需展开。
  - 单 Agent 创建与编辑作为主内容区内的二级页面（保留应用最左导航，提供“返回 Agent 列表”），内部顶部采用横向可滚动分类导航：**基础信息**（内置图案/本地上传/恢复默认头像、名称、简介）、**角色与规则**（集中切换编辑 `AGENTS.md`、`IDENTITY.md`、`SOUL.md`、`SONG.md`）、**模型与能力**、**技能与工具**（先列 Agent 专属技能与数量，再列继承的共享技能与数量，开关仅作用于当前 Agent）、**记忆与知识**（默认展示专属记忆，可切换查看已授权共享个人记忆，禁止用 Markdown 编辑器代替记忆服务）、**绑定的机器人**（仅列归属当前 Agent 的机器人，通过共享选择器改绑或移交给 Momo，列明原/目标负责人与撤销操作，保存后生效且不改历史对话归属）、**高级设置**。切换分类保留草稿，底部固定 `.settings-footbar` 保存后留在当前页并提示成功。
- **Agent 存储迁移弹窗**：
  - 必须等待服务就绪后再检测，启动或暂不可达时不弹空白错误窗；未完成迁移且关闭弹窗时在主会话区显示阻塞原因与处理入口，不提供暗示可跳过的“稍后”按钮。
  - 弹窗固定标题、并列数字摘要与底栏，仅中间正文滚动（展开诊断不产生嵌套滚动）。冲突行中目标 Agent `SelectControl` 与“不迁移此 Bot 的旧数据”组成左对齐操作组（支持确认前撤销，全部解决后才由“需要处理”变为“等待确认”）。
  - 固定底栏常驻“**强制迁移（跳过异常项）**”，说明异常源文件保留、无法关联的运行记录备份后停止恢复；完成后展示可展开的跳过记录与备份位置，提供“完成，进入应用”（写入失败严禁显示成功）。

## 3. 四大功能工作区（自动任务、技能、计划、小程序）

- **跨工作区统一框架**：
  - 四个工作区保持独立侧栏入口，不在内容区重复跨页 tabs。顶栏（42px）通过 `ChatHeader` 发布标题与单图标操作：搜索统一为顶栏图标（点击原位展开聚焦，`Escape` 或关闭清空收起并归还焦点；有保留筛选词时重入页面保持展开）；仅含刷新时直接显示刷新图标，不用更多菜单。
  - 内容区顶部展示本地化说明与单行筛选栏：自动任务分类、技能范围与计划状态均使用直接可点的**共享分段按钮**（不用下拉），每项直接显示对应数量，“全部”显示总数；窄窗筛选项横向滚动，统计摘要可收缩并通过悬浮提示保留全文。
  - 默认主题下，自动任务、计划与技能列表模式的左列（固定 `320px`）共用平面行、发丝分隔线与软选中样式；未选中对象时右侧复用 Agent City 插画与简短引导。计划页同时展示执行中、需要处理、已归档的真实计数，点击计数可切换状态筛选；加载失败时提供原地重试，不展示默认零值概览。
- **自动任务与计划看板 (Automations & Session Plans)**：
  - 两者共用相同的顶部两行说明占位、单行筛选栏与固定 `320px` 左列主从布局（窄窗切换为单列并提供返回列表入口，返回保留搜索与滚动位置，后台刷新不重选已关闭详情）。
  - **计划工作区**：计划是独立于聊天的持久化对象（稳定 ID），批准后交由 Durable Execution 执行器运行，活动与反馈留在承接 Session。详情按执行顺序展示两层任务/步骤、真实结构化进度（运行、等待授权、受阻、执行结束待检查、完成；完成后隐藏暂停/取消）、验收要求与位于标题下方的固定操作栏。已完成步骤只读；返工编辑器在正文顶部展开，以新增步骤的新版本表达并回到待批准（任一返工任务缺少名称或有效步骤时禁止添加下一项或保存）。长任务卡片文本与长链接在卡内折行，窄屏状态标签换行。任务显示顺序编号，任务与验收分区显示条目数；审批与待决定事项以独立提示区展示。返工编辑器使用单列字段、分组步骤与双栏版本对比；编辑模式收起执行控制栏，标题和底部操作栏占据独立空间，仅中间正文滚动，操作栏不覆盖正文；窄窗详情占满内容列并提供返回入口。
- **技能工作区 (Skills)**：
  - 与自动任务、计划一样铺满可用内容区宽度（仅留统一左右内边距）。默认展示紧凑中性卡片网格（无绿色侧边线，标题 + 两行说明 + 底部范围/状态/开关/内置更新入口；未安装内置技能同样以卡片呈现）。
  - 点击卡片（或 `Enter`/空格）通过 FLIP 动画变形为左列 `320px` 竖向列表 + 中列内容区（标题、完整说明、路径与点号展开的 YAML 元信息、版本与修改时间、内置版本状态、只读文件预览；Markdown 渲染，文本限 256 KB，二进制提示不可预览）+ 右列目录树（目录优先、相对路径与大小）；关闭详情 FLIP 复原。
  - 顶栏“技能维护”弹窗（查重整理、备份恢复清理、断链移除）的完整交互与边界见 [Skill 维护](../../features/skill-maintenance.md)。
- **小程序工作区 (Mini Apps)**：
  - 说明、数量工具栏、Launchpad 启动台与管理页统一约束在 `1240px` 限宽容器内。数量行左侧显示已安装与启用数，右侧显示管理图标（进入管理页后原位切换为返回启动台图标，AI 路由说明置于管理工具栏设置图标悬浮提示中，不用通栏卡片）。

## 4. 应用形象与关联功能文档

- **桌面应用图标 (Application Identity)**：通用设置外观区依次排列主题选择、主题导入与 Logo 选择（17 个形象）。切换 Logo 同时更新应用内头像、运行中 macOS Dock/应用切换器大图标（保留原图异形轮廓与透明通道，不加底板或裁切）及菜单栏托盘小图标（独立 44px 透明彩色资源，渲染为 18pt）；偏好按设备持久化并在原生启动时恢复，更新期间锁定重复提交。
- **关联专项文档**：
  - **Agent 房间（Room 首页、会话、创建与设置页）**：见 [Desktop Agent 房间指南](../agent-rooms.md)。
  - **记忆中心（四入口导航、向量存在状态、未收录记忆）**：见 [Personal Agent and Memory](../../features/personal-agent-and-memory.md)。
  - **Skill 维护与整理弹窗**：见 [Skill 维护](../../features/skill-maintenance.md)。
