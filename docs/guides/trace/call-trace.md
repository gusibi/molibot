# 调用链报告

在设置的插件列表启用 **Call Trace / 调用链**。在 APP 的回复下方点击模型信息旁的“查看调用链”（窗口较窄时该入口在“更多操作”菜单中），可以查看该回复对应执行的模型、工具、子 Agent、耗时、token 和已记录的摘要。默认从右侧抽屉展开，右上角可切换全屏；点击时间线步骤展开详情；“刷新”重新读取 trace。切换语言和明暗主题会同步应用到查看器。

入口依赖回复的真实 run ID。没有记录 run ID 的历史回复不显示入口；已有 trace 缺少父子关系时只展示已知步骤，不推断内部调用。内置子 Agent 记录内部模型和工具；外部 Agent 只展示已上报的外层执行，无法保证完整用量。

## 跨渠道与公开分享

在 Telegram、飞书请求“查看上一轮调用链并给我链接”，或引用需要查看的消息，Agent 可调用 `viewTrace`。查询限定当前 Bot、渠道、聊天与 Session。指定消息无法定位时返回错误，不改查最近一轮。平台回复 ID 在渠道最终发送或提交路径记录；未提供发送回执的渠道或历史消息可能无法通过引用定位，此时可使用原始用户消息或明确的 run ID。

APP 弹窗的“分享公开链接（不含摘要）”及 `viewTrace` 的 `publish` 参数都复用 **Cloudflare HTML Publish**。先在该插件配置 R2 和公开地址并启用。上传失败返回实际错误；本地查看不依赖 R2。

公开报告保留模型、工具、时间、状态和用量，剔除参数、结果、错误摘要、原始内部标识和根节点的 Session 名称；run ID 与节点 ID 以不可逆的匿名标识呈现。链接是公开快照，包含生成时刻，不会自动更新，也不提供链接鉴权、撤销或过期。点击公开分享代表发布这份精简报告。

## 数据口径

- 本轮耗时取起止边界，不累加并行步骤耗时；输入排队前的等待不属于执行耗时。
- token 来自模型返回的 usage，按唯一模型调用累计，包含已记录的重试和内置子 Agent。父任务汇总不重复计入。
- 缺失数据显示“未记录”，部分用量明确标注；工具自身不虚构 token。
- 参数和结果是 trace 已保存的摘要，不能恢复被截断或未记录的内容。
- 尚未结束的步骤显示已持续时间。刷新失败保留上次快照并显示错误。

## 复用接口

共享报告查询接收明确的 run ID 或受宿主限制的消息目标，返回版本化结构化数据。共用 HTML 渲染器接受该报告及语言，生成不依赖外部资源的文档。公开投影和上传是独立操作。

桌面接口为 `GET /api/desktop/trace-report`：不传 run ID 时查询插件是否启用，传一个或多个 `runId` 时返回报告和 HTML；`POST` 接收 `runIds` 与 `language`，发布精简报告。访问范围沿用现有桌面服务接口的信任模型，不将此接口作为公网认证入口。

小程序尚未实现。后续小程序应通过受控宿主桥复用报告查询与渲染能力，不直接读取宿主数据库。
