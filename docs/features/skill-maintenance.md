# Skill 维护

技能页顶栏的“技能维护”按需扫描已配置、已启用的技能目录。它不扫描整台设备，也不自动整理文件。普通技能列表继续使用轻量扫描。

## 查重与整理

“重复内容”区分内容相同的独立副本，以及同名但内容不同的副本。内容比较包含技能说明、辅助文件、内部链接和执行权限；依赖缓存、仓库元数据等沿用技能树检查器的排除规则。多个入口指向同一实体时，在“链接与引用”显示为已共用一份。

点击“选中相同内容组”可批量选择至多 100 组。不同内容的组需选择保留内容，可逐个比较其余版本：先列出不同文件，再显示文本双列对照。单对文件最多预览 128 KiB，整次比较最多预览 1 MiB；二进制、超限文件和目录／链接属性分别标注，不把空白当成内容相同。

预览会列出共享实体、原位置链接和恢复备份路径。全局技能整理到 `~/.agents/skills`；项目技能只在同一已登记项目内整理到 `.agents/skills`，不会和全局同名技能合并。Agent 专属技能没有跨工具共享目标，整理保持只读。只读平台或包含不安全文件的组不会执行。

确认后保留所选内容，将其余已列出的入口改为链接。被替换的内容和原链接保留时间戳备份。只存在于未配置或未启用目录的副本不会被发现或修改。

如果整个工具技能目录已经链接到共享目录，单个技能也已经共用实体。“整理”显示“已共享一份内容”及父目录链接路径，不作为冲突、不列出虚构写入计划；确认按钮显示“确认共享状态”，只核对状态，不再搬移或生成备份。此时“移除入口”会删除共享实体，因此拒绝执行。独立副本仍可使用“原位置改为链接”完成去重。

整理弹窗保持标题、外壳与底栏稳定，成功态复用同一外壳。信息按技能身份、原位置处理方式、路径关系、执行状态排序；三个处理方式使用等宽共享按钮与连续移动的选中底板（键盘焦点独立于选中状态）。切换处理方式立即反馈选中项并保留上次路径预览，预检完成前确认按钮锁定；快速切换只接受最后一次请求的结果，失败提供原地重试。正文反馈使用 160ms 局部透明度过渡，不动画布局尺寸。路径默认以 `~/` 简写，展开路径详情可核对完整服务端路径及父目录链接，长路径在窄窗内折行。取消或 Esc 关闭后焦点回到整理入口，减少动态效果及低性能模式禁用非必要空间过渡。

## 备份恢复与清理

“恢复备份”列出符合统一时间戳命名规则的备份。恢复会复制备份内容，当前位置存在内容时先另存备份；所选备份继续保留。备份链接恢复为其可读内容。

清理需要单独预览和确认，永久删除所列备份；链接备份只删除链接本身。已配置目录中的技能入口或辅助文件仍引用该备份时，禁止清理。

扫描本身也有边界：配置根不是目录（例如 macOS alias 文件或普通文件）不视为扫描缺口，因为其中不可能包含技能，平台页仍会把它标为配置问题；只有真正读取失败的目录或截断的扫描才算“扫描不完整”。出现这种情况时，确认框列出未读路径，并允许在“我已核对，仍要删除”后重新预检并继续——删除是单一不可逆动作，由所有者显式接受不确定性；整理、恢复和移除断链仍然硬阻塞，因为它们会改写活跃内容。警告以本地化原因加路径呈现，原始扫描器消息保留为提示。此检查不承诺发现未配置目录、其他程序或脚本中的引用。

## 断链与恢复

“链接与引用”列出入口路径、解析后的实体位置和读取它的平台，并提供断链移除操作。移除只处理所列链接，不修改缺失目标；已修复的链接会使旧计划失效。

预览绑定内容、链接关系和路径身份。执行前重新检查；文件或引用发生变化时须重新预览。整理和恢复在已有操作库记录移动计划，普通写入失败会回滚；进程中断后重新打开 Manager 会恢复未完成的可逆操作。备份清理属于不可逆操作，中断后应重新扫描，不能假定已删除的内容已恢复。
