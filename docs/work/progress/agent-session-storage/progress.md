## 实现

- 普通 Agent 使用 `sessions/<agentId>` 共享工作区。Session 是 `contexts/` 下的 JSON/JSONL 和元数据；不创建 Chat 或 Session 工作区。资源、技能、草稿、事件和运行记录共享，来源元数据与当前路由分离。
- Channel 的凭据、规则和平台状态位于 `channels/<channel>/bots/<botId>`；身份配置仍位于 `agents/<agentId>`。Project 保持独立目录与数据库语义，Room 文件复制到独立 Room runtime 路径，不纳入普通 Agent Context。
- 启动检测阻止 Runtime、队列及事件初始化。Desktop 显示摘要、冲突、确认、稍后、重开、复制/发布进度和重试；确认成功后才启动运行。健康接口区分服务存活与 Runtime 就绪，避免等待迁移时被服务管理器重复重启。
- 清单保存稳定来源映射、源校验、暂存阶段与逐文件发布记录。文件经复制校验后发布，持久队列、恢复、审批和事件租约按分域事务更新。失败后继续已校验步骤；完成映射保留目标后续修改。新增旧来源在下一次冷启动重新等待确认。
- 同名 Session 在所有 Agent 中使用唯一目标 ID。相同 Skill 去重，不同内容阻塞。附件与 scratch 保留命名空间及相对关系，历史正文不改写，文件引用经已发布映射解析；需要来源时明确拒绝歧义。
- Runtime、Runner、技能命令、历史列表、文件授权/预览、删除/导出/路径菜单均使用新布局。历史会话固定 Agent，Bot 改绑定只影响新会话。Event 保留固定 Agent、创建 Session 和完整回复目标；租约、停止及忙碌判断按渠道完整目标隔离。
