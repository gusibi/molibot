# Geist 色阶与文案参考

本文仅保留 Geist 10 阶色板（sRGB 与 Display P3）及通用界面英文文案参考（如 Bot 首字母强调色取色等场景）。

> **注意**：原 Geist 的字体（Geist Sans）、40px 默认控件尺寸、旧圆角/阴影/动效数值，以及旧 OKLCH 暗色体系均已被 Molibot 的 macOS 产品设计层替代并移除。当前界面的权威设计规范见 [DESIGN.md](../../DESIGN.md)，macOS 暗色语义角色见 [design.dark.md](../../design.dark.md)，实际 token 定义见 `apps/desktop/src/styles.css` 与 `apps/desktop/src/themes/`。

## 1. 10 阶色板参考 (Light sRGB & P3)

每个非背景色阶包含 10 个梯度（`100`–`1000`），阶数表达语义意图而非单纯明度：
- `100` 默认背景 · `200` 悬停背景 · `300` 激活背景
- `400` 默认边框 · `500` 悬停边框 · `600` 激活边框
- `700` 高对比度实心填充 · `800` 实心填充悬停
- `900` 次级文本与图标 · `1000` 主文本与图标

## 2. 界面文案简洁约定 (Voice & Content)

- **按钮命名**：采用“动词 + 名词”（如 `Delete Member` / `移除成员`），避免仅写 `OK`、`Confirm` 或孤立动词。
- **错误文案**：说明“发生了什么 + 下一步怎么处理”，而非内部异常栈。
- **轻提示 (Toast)**：直呼发生变更的对象，不加句号，不写冗余的 `Successfully`（如写 `Project deleted` 而非 `Successfully deleted the project.`）。
- **空状态**：一句话说明当前为空，并指向第一个可执行操作。
- **进行中状态**：英文使用现在分词加省略号字符（`Saving…`），中文使用“正在…”或明确阶段名称。
